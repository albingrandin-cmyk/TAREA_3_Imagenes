# Tarea_3_Imagenes
Sourcecode for Notch-reject filters, Wiener filter and Tikhonov filer with gradient descent

## Requirements
* Python 3.x
* `numpy`, `cv2`, `matplotlib`

## How the code is run
* `python pregunta_1.py` - Simulations and generates figures and prints results using Notch-reject filters for pregunta 1 with cameraman.jpg as the given image.
* `python pregunta_2.py` -  and generates figures and prints for pregunta 2 using Weiner and Tinkhonov filters.
